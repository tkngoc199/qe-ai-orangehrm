# QE-AI for OrangeHRM

## Giới thiệu | Introduction

Dự án thực hành Quality Engineering (QE) có hỗ trợ AI trên hệ thống OrangeHRM.

This repository documents my hands-on learning journey in AI-assisted Quality Engineering using the OrangeHRM application.

---

## Mục tiêu dự án | Project Goals

Sử dụng AI để hỗ trợ các hoạt động kiểm thử phần mềm.

Use AI to support software testing activities, including:

- Requirement Analysis
- Test Scenario Generation
- Test Case Design
- Test Data Creation
- Defect Analysis
- Test Automation
- Test Reporting
